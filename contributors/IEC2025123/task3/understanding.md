The code in this task is used to split expenses between people and settle debts fairly. The program calculates an average expenditure per person, those who have paid less than the average are added to the debtors list, those who have paid more than the average are added to the creditors list. The debtors list is sorted in order of the most debted person to the least and the creditors list is also sortted in order of the most credited person to the least. Then the array lists are compared from the first position to the last, if the debt is less than the credit, the pointer moves to the next debtor, similarly for the creditor unless the expenses are balanced out.

I have added the feature as instructed to track the expense in each category (If category not mentioned => Uncategorized) by adding another parameter 'category'. It displays the category wise expenses first then the transactions to be done.
